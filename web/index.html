Everything on this page comes from a small JSON API. No key, no sign-up. GET only, answers are cacheable.

RequestReturns
/api/v1/calc?q=<addr[/prefix]>[&split=<n>]Explain an address or prefix, optionally split into /n subnets (first 256 listed)
/api/v1/contains?net=<cidr>&ip=<addr|cidr>Whether the address or subnet is inside the network
/api/v1/summarize?q=<list>Exact summary and single supernet of up to 64 subnets (comma, space or newline separated)
/api/v1/meExplain the IP you connect from

Every answer has title, facts[] (label, value, why) and prompt; calc adds family, canonical, kind and split. Bad input returns HTTP 400 with {"error": "..."}.

curl -s 'https://ipcalc.franzramadhan.dev/api/v1/calc?q=2001:db8::1/64' | jq '.facts[] | {label, value}'
curl -s 'https://ipcalc.franzramadhan.dev/api/v1/contains?net=10.0.0.0/22&ip=10.0.1.77' | jq -r '.facts[] | select(.label == "Result").value'
curl -s 'https://ipcalc.franzramadhan.dev/api/v1/summarize?q=10.0.0.0/24,10.0.1.0/24' | jq '.facts[1].value'

Rate limit: 60 API requests per 10 seconds per IP, then blocked for 10 seconds. The service sleeps from 23:30 to 06:00 WIB. Source and docs: github.com/franzramadhan/ipcalc.
